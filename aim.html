Overwatch Practice Range — Unlimited Ammo

Roster

Every score, every account and every character lives on the server, so the roster is the same for everyone on every device — set your main account, your alts and the characters you train once, and it is there next time, wherever you open it. The tags you set also appear in Ranks, marked as yours.

Drills run in the Overwatch 2 Practice Range on unlimited ammo — the number you log is the result of one clean run of that drill for that hero. Heroes only appear under the drills they are meant for.

Export writes the whole dataset to a file; Import replaces it (password protected, so a stray file cannot wipe the board).
